# Repository maintenance instructions

- Treat `rules/*.md` as the source of global instructions. Keep their guidance practical, scoped, and internally consistent.
- Build output in `build/AGENTS.md` is generated by `python3 scripts/build-instructions`; edit the sources, not the generated file.
- Keep the generated global instruction file below 32 KiB and self-contained. It must not depend on repository paths or external runtime files.
- `templates/` are starting points for local repository conventions, not additional global rules.
- Preserve user-owned files. Installer changes require `--apply`; replacing different existing global instructions requires `--replace`; rollback must refuse to overwrite edits made after installation.
- Do not make scripts read or write Codex configuration or authentication files. Installation targets only `AGENTS.md` and its backup metadata.
- For changes to behavior, add or update focused standard-library tests. Verify with `python3 -m unittest discover -s tests -v` and `python3 scripts/validate`.
- Keep documentation commands runnable from the repository root. Do not commit generated build output.
